# Авторизация

Экран реализован в UIKit. Эти изображения — выбранные дизайн-концепции, а не скриншоты приложения; визуальная приёмка текущей реализации ещё требуется.

## Композиция и ввод

Оригинальный логотип Qase → «Войти в Qase» → описание → постоянная подпись «API-токен» → защищённое поле → «Войти» → «Попробовать демо». Под кнопками нет подписи или зарезервированного места. Демо использует локальные данные и не требует пользовательского токена; долгое нажатие остаётся дополнительным способом входа.

Нормативный экран — 402 × 874 pt, дополнительно поддерживается ширина 320 pt. Горизонтальные поля — 20 pt, описание ограничено шириной 320 pt. Форма центрируется с подъёмом 32 pt в доступной области; при недостатке высоты верхний отступ сокращается до 24 pt и доступна прокрутка. Safe area и клавиатура учитываются один раз.

Поле и основная кнопка — минимум 52 pt, демо — 48 pt, радиус — 12 pt; высоты растут с Dynamic Type. Боковые области поля шириной 44 pt содержат иконки 22 × 22 pt. Текст, placeholder и редактирование используют одну область с отступами 52 pt по горизонтали и 12 pt по вертикали. Глаз остаётся внутри поля; показ/скрытие сохраняет текст, выделение и фокус.

Фоны — белый/чёрный, поле — `surface.secondary`, шрифт — системный SF Pro. Основное действие использует градиент из [дизайн-системы](../../DESIGN_SYSTEM.md) с чёрным слоем 12% для белого текста. Внешняя glass-карточка и декоративное свечение не используются.

## Состояния

| Состояние | Поведение |
|---|---|
| Пустое или пробельное значение | «Войти» нейтральна и недоступна; демо доступно |
| Заполнено | Токен скрыт по умолчанию; «Войти» доступна |
| Проверка / открытие демо | Спиннер в выполняемом действии; ввод, видимость и оба действия заблокированы, повторный запрос исключён |
| Неверный токен | Ввод сохранён, ошибка под полем и красный контур; редактирование снимает сообщение |
| Соединение / другие ошибки | Ввод сохранён, безопасное сообщение под полем; поле не объявляется неверным |
| Клавиатура | Поле и «Войти» доступны над клавиатурой; демо доступно при прокрутке |

Среди HTTP-ответов `APIManager.auth` возвращает `false` только для 401; остальные non-2xx передаются типизированными ошибками. Сырые тела ответов и токены пользователю не выводятся. Ошибки озвучиваются VoiceOver, скрытое значение токена не читается. Демо не подменяет пользовательский ввод.

Размеры в pt — контракт, а не измеренные свойства растра. Реальные touch-зоны, клавиатура, Dynamic Type, VoiceOver и повторная визуальная приёмка описаны в [проверке приложения](../../../docs/DEVELOPMENT.md). Сборка, компиляция, тестовые прогоны и CI при очистке документации не запускались.
