## Выбранное направление

Строка: название слева → свободное пространство → выбранный текст → маленький цветовой маркер → стрелка выбора справа.

Текст выбранного значения — главный носитель смысла. Для серьёзности и приоритета крупный символ заменён сплошным маркером 5–6 pt сразу ПОСЛЕ текста с промежутком около 6 pt. Точка не занимает отдельную колонку и не оказывается посреди строки. Примеры: «Критичный» с красным маркером, «Средний» с синим.

Маркер использует текущий семантический цвет параметра. Декоративный цвет не заменяет текст и не вводит новую шкалу приоритетов. В остальных строках достаточно выбранного текста и стрелки; у API значок накопителя убран.

## Размеры и адаптация

- Подпись/значение сохраняют семантические стили шрифта около 17 pt с поддержкой увеличения.
- Маркер 5–6 pt, без обводки, фона, glow и отдельного нажатия.
- Вся выбранная группа выровнена вправо; нейтральная стрелка остаётся у края.
- Существующие высоты, отступы и зона нажатия всей строки сохраняются.
- Когда подпись и значение не помещаются, подпись идёт сверху, полное значение и маркер — следующей строкой слева. Стрелка остаётся справа, строка растёт по высоте.
- Для VoiceOver маркер декоративный; озвучиваются подпись, полное значение и действие выбора. Цвет не является единственным сигналом.
- Ни маркер, ни стрелка не становятся отдельной кнопкой.
