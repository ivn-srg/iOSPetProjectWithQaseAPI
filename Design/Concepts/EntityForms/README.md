## Компоновка и компоненты

Одна прокручиваемая форма, закреплена только компактная навигация. Создание: «Создание», закрытие и «Создать»; переключатель «Набор / Кейс» и проект входят в начало содержимого. Редактор: ID, Back и «Сохранить», проект в содержимом; отдельных страниц «Общие / Свойства» нет. Срезы макетов не означают новые страницы или вкладки. Нижней кнопки сохранения и постоянной подписи о несохранённых изменениях нет.

- Набор: название/описание → предусловия → родитель.
- Кейс: название/описание → предусловия/постусловия → родитель при создании → классификация → тип/уровень → автоматизация → шаги при редактировании.
- Все свойства и условия видны сразу. Редактор кейса не переносит кейс между наборами.
- Создание проекта сохраняет прежний стиль `standard`.

Сгруппированный контракт от 13 октября: `secondarySurface`, радиус 16 pt, внутренний горизонтальный отступ 16 pt, вертикальный отступ группы 0 и spacing 0. Между соседними строками — разделители 1/displayScale. Текстовая строка получает вертикальные отступы 12 pt через контейнер; строки выбора, родителя и переключателя сохраняют свои отступы 12 pt, без второго слоя padding. Поля экрана — 20 pt, промежутки групп — 16–24 pt.

Ввод прозрачный, без собственной рамки и радиуса; внутренний inset и lineFragmentPadding равны нулю. Placeholder совпадает с началом текста. Минимальная область ввода названия/кода — 44 pt, многострочного текста — 56 pt; содержимое и Dynamic Type увеличивают высоту. Под вводом индикатор 2 pt: отступ после ввода 4 pt, перед примечаниями 6 pt. Ошибка имеет приоритет над фокусом; обычное состояние прозрачно. `standard` сохраняет рамку и прежнюю геометрию.

Строка выбора минимум 52 pt: подпись → выбранный текст → точка 6 pt с интервалом 6 pt → нейтральная стрелка. Точка только у приоритета и серьёзности; «Не задано» без маркера и пустого промежутка, API без значка. Меню и ID опций сохраняются. В grouped значение использует вторичный текст. При переполнении подпись сверху, полное значение и маркер снизу слева, стрелка справа; шрифт не сжимается. Вся строка — одно действие, маркер декоративный. Цвета и прочая геометрия — в [дизайн-системе](../../DESIGN_SYSTEM.md).

Переключатель «Нестабильный тест» сохраняет положение бегунка и пояснение «Может падать без изменения условий». Родитель показывает полное название и путь; корень обозначается явно.

## Ввод, сохранение и выход

Название — единственное обязательное поле. Пустое/пробельное значение выключает основное действие; в редакторе сохранение также выключено без изменений. Первое открытие нейтрально, ошибка появляется после взаимодействия и выхода из пустого поля; исправление снимает её.

Лимит новых правок — 500 символов, с учётом Unicode и составного ввода. Счётчик виден в фокусе. Лишний ввод не сбрасывает существующий текст; нетронутый длинный текст с сервера не обрезается при фокусе/blur. Курсор раскрывается над клавиатурой. В редакторе вкладки скрываются на время клавиатуры, затем восстанавливается прежняя видимость; safe area не учитывается дважды.

| Состояние | Контракт |
|---|---|
| Валидный изменённый черновик | Верхнее действие доступно |
| Сохранение | Индикатор в верхнем действии; повтор, ввод, переключение сущности и доступные пути ухода заблокированы |
| Ошибка / таймаут | Ввод и dirty-состояние сохранены, повтор доступен после снятия занятости |
| Back / закрытие / жест / вкладка | Для dirty — «Продолжить редактирование» либо «Отменить изменения»; чистая форма уходит без диалога |
| Смена проекта / токена / выход | Существующий координатор «сохранить / отбросить / остаться»; занятость всех участников проверяется до и после ожидания решения |

Создание хранит **два независимых черновика**. Обычное «Создать» отправляет только активный тип; закрытие учитывает оба. После успеха подтверждённый снимок получает новый baseline. Если второй тип изменён, продолжение открывает его с сохранённым вводом. Возврат к первому типу без изменений не создаёт дубликат; новое создание возможно после изменения данных. Координатор сохраняет dirty-типы последовательно; при частичном успехе уже сохранённый тип повторно не отправляется. Устаревший ответ другой сессии/проекта не закрывает форму и не изменяет кеш.

## Родитель и шаги

Каталог текущего проекта — отдельная панель с закрытием, поиском и корнем, без «Готово». Нажатие выбирает в открывшийся черновик и закрывает; отмена сохраняет прежнее значение. Одна галочка у выбранной строки, в том числе корня. Выбор меняет `parentId` набора либо `suiteId` кейса; корень — `nil`.

Каталог загружается полностью с пагинацией; частичная ошибка не заменяет кеш полным пустым каталогом. Отмена, повторная загрузка и смена сессии защищены от старых ответов. Поиск локален по названию/пути; неполный кеш обозначается ограниченным состоянием с retry. Одноимённые наборы различаются полным путём; циклы и отсутствующий предок дают «Путь недоступен». Loading, error/retry, no results и пустой проект различаются; корень доступен и в пустом проекте. Для будущего редактора набора потребуется исключить сам набор и потомков.

Шаги только для чтения: номер → действие → ожидаемый результат, полный многострочный текст. Поддерживаются пустой список и отсутствие ожидаемого результата. Добавления, редактирования, удаления и перестановки шагов нет; конец списка не перекрывается вкладками.

VoiceOver получает постоянные подписи, полное значение/путь, положение переключателя и содержимое шага; ошибки связаны со своим полем, загрузка не озвучивается реальной записью. Нормативные ширины — 402 и 320 pt; пиксели растра не подтверждают размеры или доступность. [Ручная проверка и ограничения](../../../docs/DEVELOPMENT.md) централизованы в документации разработки. Сборка, компиляция, тестовые прогоны и CI при очистке не запускались; визуальная приёмка текущих экранов остаётся открытой.
