# Макеты форм кейсов и наборов — v2

Выбран пользователем вариант с точками: [компактные строки параметров v3](PARAMETER_ROWS_V3.md), [образец](parameter-rows-v3.png), [создание кейса](case-create-v3.png), [редактор кейса](case-edit-v3.png). Крупные иконки заменены маленькими цветными маркерами рядом с выбранным значением; декоративный значок API убран. Остальные листы v2 сохраняются.

План переноса: [forms-implementation-plan.md](../../../forms-implementation-plan.md). Основания по коду и уточнения: [IMPLEMENTATION_NOTES.md](IMPLEMENTATION_NOTES.md).

9 октября 2026: формы создания и единый редактор кейса реализованы в UIKit. План отмечен выполненным по коду/статической проверке. [Итоговая валидация](VALIDATION.md). Сборку, компиляцию и тесты агент не запускал; реальные скриншоты и визуальная приёмка остаются за пользовательской проверкой.

Статус: **исправленный комплект дизайн-концепций**. Замечания v1 учтены в изображениях и [контракте передачи](HANDOFF_V2.md); реальные экраны приложения ещё не проверялись.

Исходные пользовательские снимки сохранены отдельно в References: создание набора, основные поля кейса и свойства кейса. Они не перерисованы генеративно и не считаются точными копиями новых концептов.

Изображения скопированы без редактирования пикселей, побайтовое совпадение с выбранными результатами проверено. Номинальные размеры для будущей реализации — 402 × 874 pt, поля 20 pt, карточки 16 pt, строки выбора минимум 52 pt; точность этих величин текущими генеративными листами не подтверждается.

Создание набора должно подключать выбор родителя к parentId. Создание кейса сейчас использует родителя исходного контекста и игнорирует ввод parentSuite: новый каталог потребует отдельного подключения. В существующем редакторе кейса перенос между наборами не проектируется.

Исходники приложения в задаче макетов/критики не изменялись. Сборки, компиляция, тесты и CI не запускались.
