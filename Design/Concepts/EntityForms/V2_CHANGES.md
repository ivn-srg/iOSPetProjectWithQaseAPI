# Исправления макетов v2

Основание: REVIEW.md. Пять основных листов пересозданы через встроенный imagegen; добавлены два листа состояний. v1 сохранены.

| Замечание | Исправление | Образец |
|---|---|---|
| Значение toggle расходилось между темами | Выключен слева в обеих темах; включён справа показан отдельно | case-create-v2, case-edit-v2, form-adaptation-states-v2 |
| Светлые ошибки/подтверждения в dark | Тёмные поверхности с читаемым текстом | suite-edit-concept-v2, form-interaction-states-v2 |
| Разные рамки, аппаратный корпус | Плоские сопоставимые рамки, статусная область, один формат листов; числа заданы нормативно | Все листы, HANDOFF_V2.md |
| Родитель терял путь | Под выбранным названием виден путь предков | suite-create-v2, case-create-v2, adaptation |
| Корень имел другую модель выбора | Одна галочка у выбранного варианта; пример выбранного корня | parent-suite-picker-concept-v2 |
| Компоненты дрейфовали | Общая семантика символов, toggle, активной вкладки, переключателя и основного действия | Основные формы и HANDOFF_V2.md |
| Срезы выглядели страницами | Общие фрагменты соседних групп, сегмент только в начале, конец содержит предыдущие группы | case-create-v2, case-edit-v2 |
| Длинные значения не были показаны | Длинное название, путь и английское значение; отдельный узкий пример | case-create-v2, form-adaptation-states-v2 |
| Клавиатура/лимит были только миниатюрой набора | Экран кейса в создании/редакторе, счётчик на конце длинного поля | form-adaptation-states-v2 |
| Пустое поле сразу становилось ошибкой | Первое открытие отдельно от проверки после взаимодействия | form-interaction-states-v2 |
| Сохранение/выход неполны | Индикатор, сохранённое название, ошибки с вводом, подтверждения одной сущности и обоих черновиков | interaction, suite-edit, HANDOFF_V2.md |
| Нет результатов путалось с пустым проектом | Два самостоятельных состояния | parent-suite-picker-concept-v2 |

Выбранные PNG просмотрены повторно. Независимая проверка семантики не выявила серьёзных оставшихся расхождений. Формальный статус: готово как комплект дизайн-концепций с контрактом передачи; не подтверждена работоспособность приложения.

Растр не является пиксельно точной спецификацией размера контролов/начертания символов. При переносе применять HANDOFF_V2.md и токены DESIGN_SYSTEM.md; приложение проверяется отдельно. Код, сборки, компиляция и тесты не затрагивались.
