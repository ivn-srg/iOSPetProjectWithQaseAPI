## Навигация и содержимое

Работа, Репозиторий, Запуски, Дефекты и Настройки используют единственный нативный large title существующего `UINavigationController`, сворачиваемый при прокрутке. Детали, редактор и дополнительные настройки — compact title. Главная сохраняет скрытую верхнюю навигацию и крупное название проекта. Новых навигационных контейнеров нет; safe area учитывается один раз.

Компактный выбор проекта в Работе/Репозитории открывается всей областью названия и стрелки; это один элемент VoiceOver. Длинное имя переносится, touch-зона минимум 44 pt. Сохранены меню, subtitle `code · description`, галочка, loading/retry и управление проектами. Выбор общий для приложения и защищает черновики.

В корне репозитория один контекст «Корень · количество наборов · количество кейсов», без повторного чипа/заголовка. Во вложенном наборе путь содержит только предков, текущий набор назван отдельно. Счётчики и timestamp горизонтальны, пока помещаются, затем становятся вертикальными с полными подписями. Поиск, создание в текущем уровне и свайп удаления сохраняются.

Ячейка: название → ID/подзаголовок → описание → чипы → дата просмотра; отсутствующие данные не оставляют пустых интервалов. Стрелка выравнивается с первой baseline названия; строки меню без метаданных центрируются по ведущей иконке. Чипы прокручиваются горизонтально, свайп удаления доступен вне их области. VoiceOver получает полные подписи. Работа — одна карточка меню; первичная загрузка Запусков/Дефектов — три компактные строки-заглушки и один доступный статус загрузки, без hero/метрик Главной. Новых действий выполнения запуска нет.

## Настройки

Карточка аккаунта показывает реальный режим: демо или токен, без вымышленных имени/email. Группы: оформление, подключение/данные, приложение. Выход — отдельная красная строка без стрелки и фиолетового контура, с защитой черновиков.

- Тема: системная/светлая/тёмная, сохраняется и применяется к окну и модальным экранам без пересоздания корневых экранов и сброса черновиков.
- Язык отображается по `Bundle.preferredLocalizations`; действие открывает системные настройки iOS. Внутреннего переключателя локализации нет.
- Токен: пустое защищённое поле кандидата, проверка до изменения credentials; отказ или отмена сохраняет сессию. Повтор текущего токена не меняет авторизацию/черновики. При реальной замене сначала обрабатываются черновики.
- Ошибки безопасны и локализованы: credentials/401, доступ/403, сеть, timeout, сохранение и общий сбой. Сырые ответы и токены не показываются; среди HTTP-ответов `APIManager.auth` возвращает `false` только для 401, остальные non-2xx — типизированные ошибки с `Retry-After`.
- Очистка кеша требует подтверждения и ограничена текущим владельцем. Авторизация, выбранный проект, оформление и история просмотров сохраняются; сеть может снова наполнить кеш. Ошибка очистки старого кеша после смены токена показывается в новом корневом интерфейсе.
- Название, версия и сборка берутся из Bundle. Название/значение настройки помещаются горизонтально либо переносятся без уменьшения шрифта; токен озвучивается как скрытое значение.

Общие размеры, цвета и состояния — в [дизайн-системе](../../DESIGN_SYSTEM.md), единая матрица [ручных проверок](../../../docs/DEVELOPMENT.md) — в документации разработки. Реальные жесты, сворачивание заголовков, Dynamic Type, VoiceOver и предупреждения после модальных переходов ещё требуют приёмки. Сборка, компиляция, тестовые прогоны и CI при очистке документации не запускались.
