В дополнительном состоянии репозитория используется демонстрационный длинный проект и компоновочные примеры двух кейсов; это не снимок фактических данных API.

## Измерения первой итерации

Таблица относится к первой итерации, где настройки содержали одну кнопку выхода. Для полноценных настроек главным содержимым теперь является карточка аккаунта и группы параметров; значения строки «Настройки» не описывают её новую компоновку.

Координаты Y отсчитываются от верхней границы экрана. Оригинальные скриншоты 1206 × 2622 px измерены с масштабом 3 px/pt. Для новых макетов координаты нормализованы на высоту 874 pt внутри экранной панели; приведена тёмная версия. Значения округлены до 0,1 pt. Это измерения растра, а не точные размеры UIKit/SwiftUI.

| Экран | Верх текста заголовка до, pt | После, pt | Начало содержимого до, pt | После, pt | Содержимое поднято на, pt |
|---|---:|---:|---:|---:|---:|
| Настройки | 119,7 | 113,8 | 418,0 | 167,9 | 250,1 |
| Работа | 78,3 | 105,4 | 222,3 | 198,7 | 23,6 |
| Репозиторий | 118,3 | 112,5 | 442,3 | 338,5 | 103,8 |

Для настроек начало содержимого — верх карточки выхода, для Работы — верх первой иконки меню, для репозитория — верх групповой карточки наборов. Положение заголовка измерено по верхнему видимому штриху текста, а не по рамке навигационной панели.

На Работе маленький исходный центрированный заголовок был выше нового крупного. Новый заголовок заменяет прежнюю иерархию, а цель по подъёму полезного содержимого выполнена отдельно. В репозитории достигнут заданный выигрыш не менее 80 pt.

Номинальный отступ после области заголовка в настройках — 16 pt. Растровое изображение не содержит границ текстового layout-контейнера; подтвердить этот отступ и hit-зоны нужно при переносе в код.

Колонки «До» воспроизведены генератором как визуальные референсы. Числа в столбцах «до» получены по оригинальным пользовательским скриншотам, а не по воспроизведённым колонкам. Растровые макеты не являются пиксельно точным чертежом: при реализации использовать системную навигацию, семантическую типографику и реальную safe area.

## Визуальная проверка

- На каждом основном экране один крупный заголовок; в свёрнутом состоянии только компактный.
- Выбор проекта вторичен; в дополнительном состоянии длинное имя переносится на две строки.
- В корне репозитория одна строка контекста «Корень · 4 набора · 3 кейса», без отдельного чипа и второго заголовка.
- Вложенный набор исключён из пути предков и назван отдельно один раз.
- Чипы кейса стоят после описания в одном горизонтальном стеке; для наборов чипы не добавлены.
- Повторяющиеся подписи «Работа» удалены; меню собрано в одну карточку.
- Тексты читаются в обеих темах, карточки не перекрывают нижнюю панель вкладок.

Сворачивание заголовка показано как отдельное состояние и реализовано средствами UIKit. Реальное поведение прокрутки, жестов, VoiceOver и Dynamic Type требует проверки после самостоятельной сборки. В код добавлены исходники регрессионных тестов сохранения темы, смены токена и очистки кеша; они не запускались.
