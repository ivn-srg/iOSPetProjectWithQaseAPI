# Qase Mobile

Неофициальное iOS-приложение для работы с Qase TMS: просмотра проектов и тестовой документации, создания наборов и кейсов, редактирования кейсов. Демо позволяет познакомиться с интерфейсом без аккаунта и API-токена.

## Возможности

- Авторизация личным API-токеном, его замена в настройках и выход из аккаунта.
- Главная выбранного проекта: сводка, активный запуск и недавно просмотренные кейсы.
- Репозиторий: иерархия наборов, поиск кейсов, создание наборов и кейсов с выбором родителя, редактирование кейса и удаление сущностей.
- Просмотр списков и подробностей запусков и дефектов.
- Светлая, тёмная и системная темы; интерфейс на русском и английском языках.
- Кеширование загруженных данных и отдельный демо-режим с локальными данными.

Выполнение тестового запуска, редактирование набора и работа с вложениями через интерфейс пока входят в [roadmap](docs/ROADMAP.md). Наличие маршрута в сетевом API-каталоге не означает, что для него реализован экран.

## Стек и требования

- Swift, language mode 5; UIKit для навигации и форм, SwiftUI для основных разделов.
- SnapKit для UIKit-компоновки, Realm Swift для локального кеша.
- Swift Package Manager; точные зависимости зафиксированы в `Package.resolved`.
- macOS и Xcode с поддержкой iOS 18.6 или новее. В конфигурации CI указан Xcode 26.3.
- Симулятор или iPhone с iOS 18.6 или новее.

## Начало работы

1. Скачайте репозиторий и откройте `QaseAPIProj.xcodeproj` в Xcode.
2. Дождитесь подготовки зависимостей Swift Package Manager.
3. Выберите схему `QaseAPIProj` и подходящий симулятор. Для физического устройства настройте Signing Team.
4. Самостоятельно запустите приложение из Xcode.
5. Введите личный API-токен Qase либо нажмите **«Попробовать демо»**.

Реальный токен хранится в Keychain; добавлять его в исходники или документацию не требуется. Демо использует локальные JSON-данные и отдельный кеш, реальные запросы к Qase не выполняются. Вход долгим нажатием на логотип сохранён, но основной вход в демо — отдельная кнопка.

```text
QaseAPIProjTests/      Исходники unit- и регрессионных проверок
QaseAPIProjUITests/    Исходники UI-проверок
docs/                 Архитектура, разработка, API и roadmap
Design/               Дизайн-система и выбранные концепты интерфейса
.github/workflows/    Конфигурация CI
```

Работа на устройстве, доступность и визуальное совпадение требуют самостоятельной проверки.
